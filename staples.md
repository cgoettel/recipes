# Shopping-list staples

Things a kitchen is assumed to have on hand. The site's shopping list still adds up how much of each your recipes need, but tucks them into a closed "You probably have these" section at the end, so you can check what's running low instead of buying them every time.

Write each one the way it shows up in an ingredient line, one per bullet, without an amount. Matching ignores case and plurals ("bay leaves" matches "bay leaf"). The headings are only for reading; the site uses every bullet.
