# LeAnn's recipe box

Every card from my mom's painted wooden recipe box, typed up so the family can cook from it. Some are hers, some came from friends, friends from church, and Grandma Goettel, and a few were clipped from the back of a Jell-O box. They're written for a modern kitchen: butter for margarine, real measurements for "1 can".

Not every card is a keeper. That's part of the charm.
