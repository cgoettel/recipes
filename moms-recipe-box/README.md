# LeAnn's recipe box

Every card from my mom's painted wooden recipe box, typed up so the family can cook from it. Some are hers, some came from friends, friends from church, and Grandma Goettel, and a few were clipped from the back of a Jell-O box. The box itself was a Christmas present in 1974 from Aunt Diane's family, Mel, Diane, Ceci, Jeff, and Missy, with a card hoping she'd keep it for her hope chest. The recipes are written for a modern kitchen: butter for margarine, real measurements for "1 can".
